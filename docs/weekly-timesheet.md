# Доска для часов (обработка `узДоскаДляВводаЧасов`)

Недельная доска ввода часов по задачам: колонки это дни недели с понедельника по воскресенье, строки это задачи с фактом за день, часы показаны в представлении задачи. Данные хранятся в документах `узВводФактаПоЗадаче`, итоги совпадают с отчётом `узФактПоЗадачам`.

## Где найти

Обработка `узДоскаДляВводаЧасов` находится в подсистеме `узУправлениеЗадачами`. Доступ дают роли `узПользователь`, `узПользовательОграничениеДоступаЧтение` и `узПользовательОграничениеДоступаИзменение`. Доска всегда показывает факт текущего пользователя.

## Как пользоваться

- Заголовок колонки: дата, короткий день недели (`Пн`…`Вс`) и итог часов за день. Выходные выделены цветом.
- Запись дня: в одной колонке `#НомерЗадачи Наименование задачи | Часы`, например `#1234 Оплатить интернет | 2,50` (длинный текст переносится на вторую строку).
- Стрелки влево и вправо переключают неделю, средняя кнопка показывает период недели (`26.10 - 01.11`) и возвращает к текущей неделе.
- Перенос записи: перетащите запись в таблицу другого дня, дата документа сменится на этот день (часы не меняются). Запись с несколькими документами не переносится.
- Изменение часов: на доске часы не правятся. Двойной щелчок по записи открывает документ, часы меняются в нём; после записи доска обновляется.
- Новая запись: ПКМ по таблице дня, «Добавить» (или Ins). Откроется форма ввода факта с датой этого дня и вашим исполнителем, задачу выбираете в форме. Строка появится после записи документа.
- Двойной щелчок по номеру или названию задачи открывает документ записи. Если за день по задаче несколько документов или в документе несколько строк, запись показывает сумму, а двойной щелчок открывает список документов этого дня.
- Удалять строки с доски нельзя: документ отменяется или помечается на удаление в его форме или списке.

## Ограничения первой итерации

- Учитываются только проведённые и не помеченные на удаление документы. Непроведённый документ на доске не виден, поэтому можно создать второй документ на ту же задачу и день.
- Интервал `ДатаНачала`/`ДатаОкончания` документов, созданных с доски, условный: `ДатаОкончания` равна дате документа (12:00), `ДатаНачала` вычисляется вычитанием часов. При факте больше 12 часов начало попадает на предыдущий день. `Период` и `Факт` для отчётов корректны.
- Новая запись создаётся только через «Добавить»: ввода в пустую ячейку нет.
- Нет итога по задаче за неделю, итога за неделю, нормы часов, утверждения недели и просмотра чужой доски.
- «Добавить» всегда создаёт новый документ, даже если запись по задаче и дню уже есть. Такая запись станет множественной и будет редактироваться через открытие документов.
- Проведение подчиняется тем же правилам, что и ввод вручную: при включённом запрете ввода факта для основных задач и задач с подчинёнными документ не проводится, причина показывается сообщением.

## Автотесты

Тесты лежат в тестовом расширении: `tests/cfe/yaxunit/CommonModules/ОМ_узДоскаДляВводаЧасов`. Они вызывают `Обработки.узДоскаДляВводаЧасов.Создать()` и проверяют `ПолучитьДанныеНедели` и `ПеренестиЗапись`. Конфигурация запуска для vanessa-runner: `tools/yaxunit.json` (отбор расширения `yaxunit`, отчёт jUnit в `build/out/yaxunit/junit.xml`). Запуск: `vrunner test yaxunit --settings tools/yaxunit.json` с параметрами подключения к тестовой базе, как для остальных тестов проекта.
